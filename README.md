📌 Project Overview

Credit Card Fraud Detection is a Machine Learning project that predicts whether a credit card transaction is Fraudulent or Legitimate.

The project uses XGBoost Classifier for prediction and Streamlit to create an interactive web application.

🚀 Features

- Credit card fraud detection
- XGBoost machine learning model
- Interactive Streamlit web application
- Real-time transaction prediction
- Easy-to-use interface

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- GitHub

🤖 Machine Learning Model

The project uses the XGBoost Classifier to classify credit card transactions.

🎯 Prediction

The application predicts the transaction class:

0 → Legitimate Transaction

⚙️ Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Go to the project folder:

cd credit-card-fraud-detection

Install the required libraries:

pip install -r requirements.txt

▶️ Run the Application

Run the Streamlit application using:

streamlit run app.py

The application will open in your browser.
